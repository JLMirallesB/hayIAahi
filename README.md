# ¿Hay IA ahí? Ay… la música

Página de espera para la ponencia **"¿Hay IA ahí? Ay… la música"** de José Luis Miralles Bono.

## Descripción

Esta es una página estática elegante y moderna, diseñada en estilo Bauhaus Hacker, que sirve como página de espera hasta que el proyecto y los materiales de la ponencia estén disponibles.

### Contenido

- **Título**: ¿Hay IA ahí? Ay… la música
- **Resumen**: Exploración de la inteligencia artificial generativa en la creación musical
- **Ponente**: José Luis Miralles Bono
- **CV**: Información académica y profesional del ponente

## Características

- Diseño minimalista Bauhaus Hacker
- Animación de reloj de arena (hourglass) en rotación
- Efectos de carga progresiva en secciones
- Completamente responsive
- Sin dependencias externas
- Optimizado para GitHub Pages

## Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, Animaciones)
- JavaScript Vanilla

## Estructura del Proyecto

```
hayIAahi/
├── index.html      # Página principal
├── styles.css      # Estilos Bauhaus Hacker
├── script.js       # Animaciones e interactividad
└── README.md       # Este archivo
```

## Cómo usar

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. O despliégalo en GitHub Pages

## GitHub Pages

Para activar GitHub Pages:
1. Ve a Settings del repositorio
2. Busca "Pages"
3. Selecciona "Deploy from a branch"
4. Elige `main` branch y `/root` folder
5. La página estará disponible en `https://usuario.github.io/hayIAahi`
